# Showzy frontend

The Vite + React frontend for Showzy, a web platform for grassroots live music in Bengaluru.

From this directory:

```bash
npm install
npm run dev
```

From the repository root, use `npm run dev:frontend`. The frontend runs at http://localhost:5173.

The Django API is in `../backend`; root-level setup and development commands are documented in
[../../README.md](../../README.md).
